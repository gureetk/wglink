wg genkey, on the node

Keys stay home

Each private key is made on the machine that uses it, and only public keys come back. Rotate them with one command, and add a preshared key for each pair.

Safe changes over SSH

A change that cuts wglink off from a node is undone by the node itself a minute later, unless wglink confirms it over a fresh connection.

How it works

No agent: small shell scripts, embedded in the binary, run over the connections you already use.

  1. ProbeRead-only scripts report addresses, routes, ports and WireGuard configs, private keys removed.
  2. ResolvePinned values first, then ones recorded earlier, then new picks that avoid everything in use.
  3. DiffEach config is rendered and compared with the node's; hand edits show up as drift.
  4. ApplyConfigs travel without private keys; each node inserts its own and loads the change.
  5. ConfirmA fresh SSH connection cancels the node's revert timer, or the node undoes the change.

Built to be trusted with root

wglink runs as root on your machines, so it keeps its footprint small and its secrets where they belong.

  • Private keys never travelConfigs are sent without them, and each node fills in its own key as it writes the file.
  • No secrets on the controllerThe state file holds public keys, addresses and hashes. Preshared keys are compared by hash.
  • Nothing to inject intoScripts go to sh over stdin; their only inputs are a few validated, quoted variables.
  • Tested on real WireGuardCI builds networks in Linux namespaces, and fails if a key ever shows up in a script's output.

Install

Packages for Debian, Ubuntu, Fedora and RHEL install shell completions and recommend wireguard-tools. Everything is built for Linux on amd64, arm64 and armv7.

All downloads and checksums

VERSION=0.4.0 ARCH=amd64   # or arm64, armhf
curl -fsSLO "https://github.com/gureetk/wglink/releases/download/v$VERSION/wglink_${VERSION}-1_$ARCH.deb"
sudo apt install "./wglink_${VERSION}-1_$ARCH.deb"
VERSION=0.4.0 ARCH=x86_64   # or aarch64, armv7hl
curl -fsSLO "https://github.com/gureetk/wglink/releases/download/v$VERSION/wglink-$VERSION-1.$ARCH.rpm"
sudo dnf install "./wglink-$VERSION-1.$ARCH.rpm"
VERSION=0.4.0 ARCH=amd64   # or arm64, armv7
curl -fsSLO "https://github.com/gureetk/wglink/releases/download/v$VERSION/wglink_${VERSION}_linux_$ARCH.tar.gz"
curl -fsSLO "https://github.com/gureetk/wglink/releases/download/v$VERSION/SHA256SUMS"
sha256sum --check --ignore-missing SHA256SUMS
tar -xzf "wglink_${VERSION}_linux_$ARCH.tar.gz"
sudo install "wglink_${VERSION}_linux_$ARCH/wglink" /usr/local/bin/
# Go 1.26 or newer
go install github.com/gureetk/wglink/cmd/wglink@latest
