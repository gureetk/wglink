Status

wglink status asks every member for its live WireGuard state and pings each peer through the tunnel. Each pair gets one of these states:

State Meaning
ok A handshake in the last 3 minutes, or a ping reply through the tunnel.
idle No recent handshake, and --no-ping was given, so it wasn't tested.
down Both ends are up, but nothing gets through.
missing An end isn't applied yet, or its interface is down.
unknown Neither end could be reached.

One reachable end is enough to judge a link. Handshake ages are measured with the clock of the node that saw them, so clock differences between machines don't skew the result.

For scripts and monitoring:

wglink status --exit-code     # exits 2 unless every link is ok
wglink status --json          # stable JSON: states, handshake ages, round trips, bytes
wglink status --net lab       # only some networks

On a node, sudo wglink status --local shows that machine's WireGuard interfaces without needing the inventory. Peers are named from the comments wglink writes in its configs. It also runs when no wglink.yaml is found.
