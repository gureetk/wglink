Rotating keys

wglink rotate makes new key pairs on the members themselves and gives the new public keys to their peers:

wglink rotate lab          # every member of lab that wglink reaches
wglink rotate lab nas pi   # only these

Like apply, it shows the plan and asks before changing anything. Members load their new keys live. In a network with preshared keys, a rotated member also gets a new one for each of its pairs. If a rotation stops partway, the next plan finds the configs and interfaces still on an old key, and apply finishes the job.

A manual node's private key is only on the device, so it gets a new pair from wglink export lab phone --new-key. Load that config on the device, then run wglink apply so its peers take the new public key.
