Install

From v0.4.0, each release has .deb and .rpm packages for amd64, arm64 and armv7. They install shell completions for bash, zsh and fish, and recommend openssh-client and wireguard-tools:

VERSION=0.4.0
# Debian, Ubuntu and relatives: amd64, arm64 or armhf
curl -fsSLO "https://github.com/gureetk/wglink/releases/download/v$VERSION/wglink_${VERSION}-1_amd64.deb"
sudo apt install "./wglink_${VERSION}-1_amd64.deb"
# Fedora, RHEL and relatives: x86_64, aarch64 or armv7hl
curl -fsSLO "https://github.com/gureetk/wglink/releases/download/v$VERSION/wglink-${VERSION}-1.x86_64.rpm"
sudo dnf install "./wglink-${VERSION}-1.x86_64.rpm"

Or download the archive for Linux on amd64, arm64 or armv7:

VERSION=0.4.0 ARCH=amd64
curl -fsSLO "https://github.com/gureetk/wglink/releases/download/v$VERSION/wglink_${VERSION}_linux_$ARCH.tar.gz"
curl -fsSLO "https://github.com/gureetk/wglink/releases/download/v$VERSION/SHA256SUMS"
sha256sum --check --ignore-missing SHA256SUMS
tar -xzf "wglink_${VERSION}_linux_$ARCH.tar.gz"
sudo install "wglink_${VERSION}_linux_$ARCH/wglink" /usr/local/bin/

Or build it with Go 1.26 or newer:

go install github.com/gureetk/wglink/cmd/wglink@latest

wglink runs on one machine, the controller, which can be one of the nodes too. Every node needs:

  • Linux with sh, ip (iproute2) and wireguard-tools (wg and wg-quick).
  • Root, or passwordless sudo for the user wglink connects as.
  • The WireGuard kernel module, which Linux has included since 5.6, or wireguard-go.
  • Optionally ping (for status) and systemd (so tunnels come back after a reboot).
