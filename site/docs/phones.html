Phones and other devices

Some peers are devices wglink can't reach, such as phones, tablets or a friend's laptop. Add them as manual nodes. wglink gives them an address and adds them to every other member's config, and you load their own config on the device:

wglink node add phone --manual --keepalive 25
wglink net join lab phone
wglink export lab phone -o phone.conf    # makes the phone's key pair
qrencode -t ansiutf8 < phone.conf        # scan it with the WireGuard app
wglink apply                             # the other members accept the phone

The phone's private key is only in that exported config; wglink keeps just the public key. If the device already has a key, pass its public key with --pubkey instead. When the phone's config changes, for example because a member joined or moved, wglink plan says so and wglink export gives the new one.
