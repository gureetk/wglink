Dashboard

wglink ui opens a dashboard in the terminal with every network and the health of its links, checked again every 10 seconds (--every changes that). Pick a network with the arrow keys, press p to see its plan, and a to apply it after a confirmation, the same as wglink apply.

You can build networks there too. n adds a node, reached over SSH, as a Proxmox container or VM, or as a phone. c connects nodes: check the ones to join, name a new network or one that exists, and pick a hub, IPv6 or preshared keys for a new one. The dashboard plans it next, so a applies it. Both forms change wglink.yaml the way wglink node add and wglink connect do.

NETWORKS       network lab   wg-lab   10.99.0.0/24   udp/51820
