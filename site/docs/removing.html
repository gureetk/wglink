Removing nodes and networks

apply also takes away what wglink.yaml no longer has. On each node it stops the interfaces that wglink wrote and that aren't wanted any more, and deletes their configs and keys:

wglink net leave lab pi    # pi loses wg-lab, and the others drop it as a peer
wglink net rm road         # every member loses wg-road
wglink apply

Take a node out of its networks and apply before wglink node rm, since wglink can't reach a node once it's out of the inventory. If the node is removed first, plan names the interfaces left on it, to delete by hand. wglink never removes a config it didn't write.
