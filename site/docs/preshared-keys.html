Preshared keys

WireGuard can mix a preshared key into each pair's handshake on top of the key pairs, a second layer that guards against a future break of Curve25519. Turn it on for a network:

wglink connect pve1 nas vps --name lab --psk
wglink net set lab --psk          # or for an existing network

apply then makes a key for every pair of peers and stores it on both, as /etc/wireguard/IFACE.psk.PEER with mode 0600, before either config uses it. plan compares keys by their SHA-256 hashes, so it can tell when a pair doesn't match, or a new key isn't loaded yet, without the keys leaving the nodes. wglink rotate replaces a member's preshared keys along with its key pair. For a phone, each wglink export makes new keys: its peers store theirs, and the config carries the phone's.
