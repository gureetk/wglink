The inventory

Commands such as wglink node add and wglink connect edit wglink.yaml for you, keeping its comments and layout. You can also edit it by hand. wglink looks for it in the directory given by --dir or $WGLINK_DIR, or else in the current directory, then ~/.config/wglink. A typical file:

version: 1

defaults:
  pool: 10.99.0.0/16 # automatic subnets come from here
  prefix: 24 # size of each automatic subnet
  port: 51820 # first listen port tried

nodes:
  pve1:
    ssh: root@192.168.1.10
  nas:
    ssh: admin@nas.lan
    sudo: true
    endpoint: 192.168.1.20
  ct101:
    pct: {via: pve1, vmid: 101}
    endpoint: 192.168.1.101
  laptop:
    local: true
    endpoint: none
    keepalive: 25

networks:
  lab:
    members:
      pve1: auto
      nas: ".10" # pinned: host 10 of the subnet
      ct101: auto
  laptop-nas:
    members: [laptop, nas]

Each node is reached one way, with ssh, local, exec, pct, qm or manual; see Reaching machines and Phones and other devices. Its other settings are optional:

Setting Default
sudo off become root with sudo -n, on ssh and local nodes
endpoint for ssh nodes, the host SSH connects to address peers dial: a host, with :port if it isn't the network's, or none
keepalive the network's seconds between keepalives to its peers, for a node behind NAT
service auto how tunnels start: systemd uses wg-quick@IFACE, so they come back after a reboot; none runs wg-quick alone; auto picks systemd where it runs

Each network becomes one WireGuard interface on each member (wg-lab here) with every other member as a peer. A node can be in several networks. A network's members are a list of node names, or a map from each name to its address: auto, a host part such as ".10", or a full address. A member that routes subnets is written nas: {ip: ".10", routes: [192.168.50.0/24]}, where ip can be left out.

Network settings, all optional:

Setting Default
subnet the first free /24 in the pool IPv4 subnet for tunnel addresses
port the first port from 51820 free on every member UDP listen port
iface wg-NAME interface name
mtu chosen by wg-quick
keepalive off seconds between keepalives, for members behind NAT
hub none: a full mesh member the others connect through
psk off a preshared key for each pair of peers
ipv6 off auto for a random unique local /64, or a subnet

What wglink picks is recorded in wglink.state.json next to the inventory, so addresses don't move when you add members later. The state file holds public keys, addresses and hashes, and no secrets. Keep both files together, for example in a private git repository. If the state file is lost, wglink state rebuild recovers it from the configs on the nodes.
