Overview

Connect Linux machines over WireGuard from one inventory file. List your machines in wglink.yaml, preview the change with wglink plan, make it with wglink apply, and check each tunnel with wglink status.

wglink is one static binary with no agent, no coordination server and no account. It reaches machines the way you already do: SSH, local commands, docker exec, and Proxmox containers and VMs. What it leaves behind are ordinary wg-quick configs that keep working without it. Private keys are made on the machines that use them and never leave.

wglink connect pve1 nas pi --name lab
wglink apply

$ wglink status
network lab   wg-lab   10.99.0.0/24   udp/51820
  pve1  10.99.0.1       up
  nas   10.99.0.2       up
  pi    10.99.0.3       up

  pve1 <-> nas  ok  handshake 14s ago, ping 0.4 ms  rx 1.2 MiB  tx 880.0 KiB
  pve1 <-> pi   ok  idle, ping 1.1 ms
  nas <-> pi    ok  handshake 1m ago, ping 0.9 ms   rx 52.3 KiB  tx 61.0 KiB

All 3 links are ok.

Features

  • Full-mesh or hub-and-spoke networks between any Linux machines: bare metal, VMs, containers, Raspberry Pis, Proxmox hosts and their guests, plus phones and other devices you set up by hand.
  • Automatic addressing that stays put. Subnets, ports and tunnel addresses are picked for you, kept across runs, and chosen to avoid addresses, routes and ports already in use on each machine. Pin any of them when you care: a host part (.10), a full address, a subnet or a port.
  • IPv6, preshared keys and key rotation. Give any network a unique local IPv6 subnet and every pair of peers a preshared key, and replace keys with one command.
  • Plan before you apply. Every change is previewed. Peer changes load live with wg syncconf; only address, port and MTU changes restart an interface.
  • Drift detection. Edits made by hand on a machine show up in plan and status, and apply puts the file back.
  • Health at a glance. status judges every link from handshakes and pings through the tunnel. It prints JSON for scripts, gives exit codes for monitoring, and has --local mode for checking one machine by itself. wglink ui keeps it all on screen, with plan and apply a key away.
  • Agentless. wglink sends small POSIX sh scripts over stdin to the machines it manages. They need only wireguard-tools, and nothing of wglink's stays running on them.
  • Careful by default. wglink won't overwrite configs it didn't write, keeps a backup of every config it replaces, and lets only one apply run at a time per inventory. A change that cuts wglink off from an SSH node is undone by the node itself a minute later.
