IPv6

Networks carry IPv4 by default. Add IPv6 inside the tunnels with --ipv6:

wglink connect pve1 nas vps --name lab --ipv6       # a random unique local /64
wglink net set lab --ipv6=fd12:3456:789a::/64       # or a fixed subnet

Each member gets the IPv6 address with the same host number as its IPv4 one, so 10.99.0.5 goes with fd12:3456:789a::5. The random subnet follows RFC 4193, so networks set up apart won't clash if you join them later. Like the IPv4 subnet, it's recorded at the first apply and kept.

In a hub network, the hub forwards IPv6 for its WireGuard interface alone on Linux 6.17 and later. Older kernels forward IPv6 only with it on for the whole machine (net.ipv6.conf.all.forwarding=1), and plan warns until it is. Endpoints can be IPv6 addresses too.
